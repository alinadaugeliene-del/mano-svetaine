# Alinos portfolio svetainė

Paprasta svetainė be jokių programų diegimo: `index.html` (tekstai), `style.css` (spalvos ir išvaizda), `script.js` (meniu ir animacijos).

**Kaip pakeisti tekstą:** GitHub atsidaryk `index.html`, spausk pieštuko ikoną, pakeisk tekstą ir spausk „Commit changes“. Vercel per ~1 min. automatiškai atnaujins svetainę.

**Kaip pakeisti spalvas:** `style.css` failo viršuje pakeisk `--accent` spalvą.
